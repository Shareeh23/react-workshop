# Forms with React

A small React and TypeScript project built to practise form handling, controlled inputs, validation, and conditional rendering.

## Features

- Controlled inputs using `useState`
- Reusable form validation utilities
- Field-level validation on blur
- Validation feedback with conditional rendering
- Password confirmation
- Form submission handling
- Success message after valid submission
- Reusable form and success message components
- Tailwind CSS styling

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

## Purpose

This project is a practice exercise focused on handling forms in React using native HTML form elements, controlled inputs, and `useState`.

It explores simple client-side input validation, inline validation feedback, event handlers such as `onChange`, `onBlur`, and `onSubmit`, and conditional rendering.

**This is not a production-ready form implementation.** It does not implement input sanitization, comprehensive validation, or real authentication. The goal is to practise React form handling fundamentals and state management.
